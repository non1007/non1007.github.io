Class: SepiaEffect

SepiaEffect(graphicsDevice)

[EN] Applies a sepia color filter post effect. [JP] セピア色のカラーフィルタポストエフェクトを適用するポストエフェクト。

Constructor

new SepiaEffect(graphicsDevice)

[EN] This effect tints the rendered scene with a sepia tone, often used to give a nostalgic or cinematic look. [JP] レンダリングされたシーンをセピア調に着色します。ノスタルジックや映画的な雰囲気を演出するために使用されます。 Example / 使用例: ```javascript var effect = new SepiaEffect(app.graphicsDevice); effect.amount = 0.8; cameraEntity.camera.postEffects.addEffect(effect); ```
