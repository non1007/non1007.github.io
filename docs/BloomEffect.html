Class: BloomEffect

BloomEffect(graphicsDevice)

Post-processing Bloom effect. Extracts bright parts of the image, applies Gaussian blur, and blends them back for a glowing effect. [EN] Post-process Bloom effect. Extracts bright areas, applies Gaussian blur, and blends for glow. [JP] ポストプロセスのブルーム効果。明るい部分を抽出し、ガウスぼかしを適用して光のにじみを再現します。

Constructor

new BloomEffect(graphicsDevice)

Parameters:
Name Type Description
graphicsDevice GraphicsDevice The graphics device of the application.
Properties:
Name Type Description
bloomThreshold number [EN] Only pixels brighter than this threshold will bloom. Range [0, 1]. [JP] この閾値より明るいピクセルのみブルーム対象になります。範囲 [0, 1]。
blurAmount number [EN] Controls the blur radius used in the Gaussian blur. Larger values = softer glow. [JP] ガウスぼかしの半径を制御します。大きい値ほど光のにじみが広がります。
bloomIntensity number [EN] Final strength of the bloom effect. [JP] ブルーム効果の最終的な強さ。
