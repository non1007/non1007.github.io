Class: OutlinePostEffect

OutlinePostEffect(device)

[EN] Post effect that draws outlines around objects using depth buffer. [JP] 深度バッファを用いてオブジェクトにアウトラインを描画するポストエフェクト。

Constructor

new OutlinePostEffect(device)

[EN] This effect detects edges by comparing depth differences of neighboring pixels. Useful for highlighting 3D models or gameplay elements. [JP] 隣接するピクセルの深度差を比較して輪郭を検出し、アウトラインを描画します。 キャラクターやアイテムの強調表示などに利用できます。 Usage / 使用例: ```javascript var effect = new OutlinePostEffect(app.graphicsDevice); effect.outlineThickness = 2.0; effect.outlineColor = [1, 0, 0]; // 赤いアウトライン cameraEntity.camera.postEffects.addEffect(effect); ```
Parameters:
Name Type Description
device GraphicsDevice [EN] The graphics device, usually `app.graphicsDevice`. [JP] 利用中の GraphicsDevice。通常は `app.graphicsDevice` を渡します。
Properties:
Name Type Description
outlineThickness number [EN] Outline thickness in pixels. [JP] アウトラインの太さ（ピクセル単位）。
outlineColor Array.<number> [EN] Outline color in RGB (array of 3 floats). [JP] アウトラインの描画色（RGB配列、0〜1の値）。
outlineDepthThreshold number [EN] Minimum depth difference to trigger outline detection. [JP] 輪郭を検出するための深度差のしきい値。
nearClip number [EN] Near clipping plane of the camera. [JP] カメラのニアクリップ距離。
farClip number [EN] Far clipping plane of the camera. [JP] カメラのファークリップ距離。
maxOutlineDistance number [EN] Maximum distance where outline is visible (fades beyond this). [JP] アウトラインが表示される最大距離（これを超えるとフェードアウト）。
