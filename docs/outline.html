Class: outline

outline()

[EN] PlayCanvas script to add `OutlinePostEffect` to a camera. [JP] カメラに `OutlinePostEffect` を追加する PlayCanvas スクリプト。

Constructor

new outline()

[EN] Attach this script to a camera entity to enable outline rendering. Attributes allow customization of thickness, color, depth threshold, and distance. [JP] このスクリプトをカメラエンティティにアタッチすると、アウトライン描画が有効になります。 属性で太さ・色・しきい値・距離などを調整できます。
Properties:
Name Type Description
outlineThickness number Outline Thickness / アウトラインの太さ EN: Outline thickness in pixels. JP: アウトラインの太さ（ピクセル単位）。
outlineColor pc.Color Outline Color / アウトラインの色 EN: Color of the outline. JP: アウトラインの描画色。
outlineDepthThreshold number Depth Threshold / 深度しきい値 EN: Depth difference to trigger outline. JP: 輪郭を検出するための深度差。 　　0.05ぐらいがちょうど良い。 値が小さいほどすぐ深度差を検知し、線だらけになる。 値が大きくなると、深度差が検知しにくくなり、線が少なくなる。
maxOutlineDistance number Max Outline Distance / 最大表示距離 EN: Outline fades beyond this distance. JP: この距離を超えるとアウトラインがフェードします。 値が小さいほど、近くのものにしか線がつかない。 値が大きくなると、ほぼ全てのものに線がつく。
